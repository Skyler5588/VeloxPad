# VeloxPad
Well my beautifull macropad, Veloxpad.
# Features
- A small oled screen for animations, or whatever you need.
- 8 Cherry MX-style keys for shortcuts to improve your speed.
- 8 beautifull WS2812B RGB LEDs
- An EC11 Rotary encoder

# CAD model
Made in FreeCAD, uses 5 M3 bolts and heatset inserts. 4 for the case and 1 for the PCB.
The case is printed in 3 separate pieces.
